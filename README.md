# Interactive Python Calculator

This project is a command-line-based calculator built using Python. It performs basic arithmetic operations with proper input validation and error handling, simulating a real calculator experience.

## Project Overview

This calculator allows users to perform operations such as addition, subtraction, multiplication, and division in a continuous loop. It is designed to handle invalid inputs gracefully and prevent runtime crashes using exception handling.

The goal of this project was not just to perform calculations, but to build a reliable and user-friendly program that behaves like a real-world application.

## Features

- Continuous execution using a loop (runs until the user exits)
- Supports basic arithmetic operations (+, -, *, /)
- Handles division by zero
- Input validation using try/except
- Operator validation for better user experience
- Clean and structured control flow

## Example Usage

```text
Enter first number: 10
Enter an operator or exit: /
Enter second number: 2
Result: 5.0
```

## Key Concepts Used

- Python loops (while)
- Conditional statements (if, elif, else)
- Exception handling (try, except)
- Input validation
- Control flow logic

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/prajsoni/interactive-python-calculator.git
```

2. Navigate to the folder:

```bash
cd interactive-python-calculator
```

3. Run the program:

```bash
python calculator.py
```
